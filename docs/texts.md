# Тексты Most Files — справочник

Все пользовательские строки — в `internal/docsbot/telegram/texts.go` и `internal/docsbot/telegram/converter/texts.go`. Основание — ревью `docs/reviews/texts-2026-11.md`.

## Голос
- Имя бота — **Most Files**, везде.
- Обращение на «ты». Бот говорит от первого лица, в мужском роде: «сохранил», «нашёл», «прислал».
- Без канцелярита, без «Успешно!», без лишних восклицаний.
- У каждой ошибки есть действие. Где уместно, успокоить: «документы на месте».

## Термины
| Пишем | Не пишем | Значение |
|---|---|---|
| документ | файл (про сохранённое) | то, что хранится в боте: название, категория, карточка |
| файл | — | то, что присылают или получают; файл на Google Диске |
| Google Диск | Диск, Drive | всегда полностью |
| на Google Диске / на Google Диск | в Google Диске | предлог |
| загрузить на Google Диск | выгрузить, перенести | одно действие для одного документа и для пакета |
| категория | папка (в боте), входящая папка | раздел каталога в боте |
| папка | — | только на Google Диске. Корневая называется «Most Docs» (`DRIVE_ROOT_FOLDER`); в текстах — только через `%s` |
| название | имя | у документа |
| оригинал | исходный файл | при замене после конвертера |
| прислать | скачать, отправить | бот присылает файл в чат |
| JPG | JPEG | формат |

## Эмодзи — одно значение, одна иконка
| Иконка | Значение |
|---|---|
| ☁️ | Google Диск: есть там, открыть, загрузить |
| 📥 | только в Telegram (показываем, только когда Google Диск подключён) |
| 📤 | прислать в чат |
| ⏳ | идёт процесс |
| ⚠️ | ошибка, нужно действие |
| ✅ | итог: подключено, готово |
| 🗑 | удалить документ или данные |
| ➖ | убрать страницы |
| 🛠 | конвертер |
| 🗂 | категория |
| 📁 | папка на Google Диске |
| 📂 | каталог «Мои документы» |

«Отмена» пишется без иконки.

## Кнопки
- Длина с эмодзи: одна кнопка в ряду — до 24 символов, две — до 15, три — до 10.
- Кнопка — глагол или объект действия. Состояние пишется в тексте сообщения.
- Подтверждение: «Да, ‹глагол›» + «Отмена».
- Без сокращений («стр.»).

## Типографика
- Полное предложение заканчивается точкой. Статусы, подписи и тосты — без точки.
- Между числом и единицей — неразрывный пробел ` `: `20 МБ`, `340 КБ`, `12 стр.`.
- Кавычки «ёлочки», тире «—» с пробелами, буква «ё». Слэш заменять на «или».
- Число перед существительным — через `plural()`: 1 документ, 2 документа, 5 документов. Формат подписи «Документов: 5» допустим.
